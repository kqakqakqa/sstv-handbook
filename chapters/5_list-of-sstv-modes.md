### Notes:

- *a* &ndash; VIS code order: Normal, Narrow mode, QRM mode, Narrow&thinsp;+&thinsp;QRM;
- *b* &ndash; Scottie DX and AVT 188 were created at the same time and accidentally share the same VIS code;
- *c* &ndash; VIS codes for each color component (red, green, blue). The green component is commonly used for BW images;
- *d* &ndash; Uses 16-bit VIS (see [**Modes MP, MR, ML**](chapters/4_formats-of-sstv-transmission#modes-mp-mr-ml));
- *e* &ndash; Uses another digital code N-VIS (see [**Modes MP, MR, ML**](chapters/4_formats-of-sstv-transmission#modes-mp-mr-ml));
- *f* &ndash; Uses odd parity;
